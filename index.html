01

Az adatbázis-tervezés alapjai

Az adatbázis strukturáltan tárolt adatok összessége. Az adatbázis-tervezés célja, hogy az adatokat logikus, hatékony és könnyen kezelhető szerkezetben tároljuk.

🗄️

Adatbázis

Összetartozó adatok rendezett gyűjteménye.

📊

Tábla

Az adatok sorokban és oszlopokban történő tárolására szolgál.

📋

Rekord

A tábla egy teljes sora.

🔤

Mező

A tábla egy oszlopa, amely egy tulajdonságot tárol.

02

Redundancia

Redundanciáról akkor beszélünk, amikor ugyanazt az információt szükségtelenül több helyen tároljuk.

⚠️ Példa

Ha egy osztályfőnök neve minden tanuló rekordjában külön szerepel, akkor ugyanazt az adatot többször tároljuk.

Tanuló Osztály Osztályfőnök
Kovács Péter 9.A Nagy Béla
Kiss Anna 9.A Nagy Béla
Szabó Péter 9.A Nagy Béla
💡 Megoldás

Az adatokat megfelelően különálló táblákba szervezzük. Ezt a folyamatot normalizálásnak nevezzük.

03

Anomáliák

Az anomália az adatbázis nem megfelelő szerkezete miatt kialakuló probléma.

➕

Beszúrási anomália

Egy új adat csak egy másik adat rögzítésével együtt vehető fel.

✏️

Módosítási anomália

Ugyanazt az adatot több rekordban kell módosítani.

🗑️

Törlési anomália

Egy rekord törlésével más, fontos információ is elveszhet.

04

Redundancia csökkentése

A redundancia csökkentésének egyik legfontosabb eszköze a normalizálás.

🎯 A normalizálás célja:
  • felesleges adatismétlés csökkentése
  • adatellentmondások elkerülése
  • anomáliák megszüntetése
  • az adatbázis könnyebb karbantartása
05

ER-modell

Az ER-modell az adatbázis logikai felépítésének megtervezésére szolgáló modell.

🔷

Egyed

Olyan objektum, amelyről adatokat tárolunk.

Példa: TANULÓ, TANÁR, OSZTÁLY

🔹

Tulajdonság

Az egyed valamely jellemzője.

Példa: név, életkor, cím

🔗

Kapcsolat

Megmutatja, hogy az egyedek hogyan kapcsolódnak egymáshoz.

ER-jelölések

▭ Téglalap → egyed

◯ Ovális → tulajdonság

◇ Rombusz → kapcsolat

06

Elsődleges és idegen kulcs

🔑 PK – Primary Key

Az elsődleges kulcs egyértelműen azonosítja a tábla rekordjait.

Egyedi és nem lehet NULL értékű.

🔗 FK – Foreign Key

Az idegen kulcs egy másik tábla elsődleges kulcsára hivatkozik.

TanuloID Név OsztalyID
1 Kovács Péter 10
2 Kiss Anna 10
💡 Megjegyzés

A TanuloID lehet PK, míg az OsztalyID FK, ha az OSZTÁLY táblára hivatkozik.

07

Kapcsolattípusok

OSZTÁLY Egy osztály
1 → N
TANULÓ Több tanuló

1 : 1

Egy rekordhoz pontosan egy másik rekord tartozik.

Példa:

Személy ↔ Útlevél

1 : N

Egy rekordhoz több másik rekord tartozhat.

Példa:

Osztály → Tanulók

N : M

Mindkét oldalon több rekord kapcsolódhat.

Példa:

Tanuló ↔ Tantárgy

08

SQL – CREATE utasítás

A CREATE utasítással adatbázisokat és táblákat hozhatunk létre.

Adatbázis létrehozása

CREATE DATABASE iskola;

Adatbázis kiválasztása

USE iskola;

Tábla létrehozása

CREATE TABLE tanulo (
    TanuloID INT PRIMARY KEY,
    Nev VARCHAR(100),
    Osztaly VARCHAR(10),
    Eletkor INT
);
🧠 Mit jelent?

CREATE TABLE → tábla létrehozása

PRIMARY KEY → elsődleges kulcs

INT → egész szám

VARCHAR → szöveges adat

Idegen kulcs létrehozása

CREATE TABLE tanulo (
    TanuloID INT PRIMARY KEY,
    Nev VARCHAR(100),
    OsztalyID INT,

    FOREIGN KEY (OsztalyID)
        REFERENCES osztaly(OsztalyID)
);
